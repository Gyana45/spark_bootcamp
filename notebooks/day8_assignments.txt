## Assignment 1: Cache vs Persist in Real Life

### Objective

Understand **when caching helps**, **what gets cached**, and **storage levels**.

### Tasks

1. Load a large dataset (for example orders with at least 50M rows).
2. Apply 3 transformations:

   * filter by date
   * add a derived column
   * group by state
3. Run an action (`count`) twice **without cache**.
4. Now apply:

   * `df.cache()`
   * run the same action twice
5. Repeat using:

   * `persist(StorageLevel.MEMORY_AND_DISK)`

### Questions to Answer

* Did the second action run faster? Why or why not?
* In Spark UI, which stages were skipped after caching?
* What happens if cached data does not fit in memory?
